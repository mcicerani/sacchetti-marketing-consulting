# UI/UX Pro Max - Design Intelligence Skill

This comprehensive design intelligence system provides structured guidance for web and mobile UI/UX development across 10 technology stacks.

## Core Capabilities

The skill encompasses **50+ design styles, 161 color palettes, 57 font pairings, 161 product types, 99 UX guidelines, and 25 chart types**. It covers React, Next.js, Vue, Svelte, SwiftUI, React Native, Flutter, Tailwind, shadcn/ui, and HTML/CSS.

## When to Apply

Invoke this skill for tasks involving UI structure, visual design decisions, interaction patterns, or user experience quality. Essential applications include:

- Designing new pages and applications
- Creating or refactoring UI components
- Selecting color schemes, typography, and spacing systems
- Reviewing UI code for accessibility and consistency
- Implementing navigation, animations, and responsive behavior

## Priority-Based Rule Categories

The system organizes guidance across 10 priority levels:

1. **Accessibility** (CRITICAL) - Contrast ratios, focus states, keyboard navigation, ARIA labels
2. **Touch & Interaction** (CRITICAL) - Target sizes (44×44px minimum), spacing, loading feedback
3. **Performance** (HIGH) - Image optimization, lazy loading, layout stability
4. **Style Selection** (HIGH) - Pattern consistency, avoiding emoji icons, platform adaptation
5. **Layout & Responsive** (HIGH) - Mobile-first design, viewport configuration, breakpoints
6. **Typography & Color** (MEDIUM) - Line height (1.5-1.75), semantic tokens, contrast verification
7. **Animation** (MEDIUM) - Duration (150-300ms), meaningful motion, reduced-motion support
8. **Forms & Feedback** (MEDIUM) - Visible labels, error placement, progressive disclosure
9. **Navigation Patterns** (HIGH) - Bottom nav limits (≤5 items), deep linking, back behavior consistency
10. **Charts & Data** (LOW) - Chart type matching, accessible colors, legends and tooltips

## Workflow

The recommended process follows four steps:

**Step 1:** Extract requirements (product type, audience, style keywords)

**Step 2:** Generate design system using the `--design-system` flag - "Always start with this"

**Step 3:** Supplement with detailed domain searches as needed (style, color, typography, UX)

**Step 4:** Apply stack-specific guidelines for implementation

## Key Design Principles

The skill emphasizes several foundational concepts:

- **Semantic color tokens** replace hardcoded hex values across components
- **Safe-area compliance** ensures fixed UI respects notches and gesture areas
- **8dp spacing rhythm** maintains consistent visual intervals
- **Vector-based icons** replace emoji for professional appearance
- **Platform-native gestures** avoid conflicts with system navigation
- **Interruptible animations** allow immediate user response

## Pre-Delivery Validation

The comprehensive checklist verifies visual quality, interaction responsiveness, light/dark mode parity, layout integrity across devices, and accessibility conformance before implementation.
